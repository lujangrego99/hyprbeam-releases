# hyprbeam — versiones

Instaladores de **hyprbeam**: un teclado y un mouse para todas tus computadoras
(Omarchy/Hyprland, Windows y un control remoto en Android).

Página: https://hyprbeam.toyfyw.easypanel.host

## Instalar

- **Omarchy / Hyprland**
  ```bash
  curl -fsSL https://raw.githubusercontent.com/lujangrego99/hyprbeam-releases/main/install.sh | bash
  ```
- **Windows**: `hyprbeam-X-setup.exe` de la [última versión](../../releases/latest).
- **Android**: `hyprbeam-X-android.apk` de la [última versión](../../releases/latest).

Una vez instalado, hyprbeam avisa cuando hay versión nueva y se actualiza desde la app.

Este repositorio solo publica los instaladores; hyprbeam es software libre (GPL-3.0).
